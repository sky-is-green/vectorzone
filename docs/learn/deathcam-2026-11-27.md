# Death camera, match-end AA, and spectator HUD — 2026-11-27

## Problems

- Ambient AA updated outside the match-phase check and kept launching after
  `world.phase` became `over`.
- Spectator selection/camera switched on the same frame the player died.
- Bomber bomb damage discarded attribution, so a plane kill looked like an
  environmental death.
- Spectator text sat just below center and overlapped the viewed tank.

## Changes

- `AmbientAa.clear()` removes active shells; the renderer stops AA updates when
  the match is over and lets existing particles fade.
- Explosions carry optional `by` attribution. Bomber bomb telegraphs retain the
  bomber id through impact damage and `tankKilled`.
- A client-only death-camera state machine provides:
  - 0.9 s wreck/explosion focus when a living killer exists;
  - 1.4 s focus on that tank/bomber;
  - 2.2 s wreck focus when no killer can be shown (missile/environment).
- Spectator selection and HUD are gated until the death sequence completes.
- Game-over UI waits for the death sequence when the player's death ends the
  match.
- Spectator controls use a translucent band at 68% viewport height.

## Killed-by follow-up

- Damage source (`shell`, `missile`, `bomb`, `volcano`, etc.) is retained through
  cell damage and emitted on `tankKilled`; environmental hits clear stale tank
  attribution.
- `killedByLabel()` produces distinct labels such as `AI-3`, `SUPERTANK AI-4`,
  `MISSILE`, `BOMBER`, `VOLCANO`, and `SELF-DESTRUCT`.
- The label remains visible for the whole deathcam.
- Killer focus no longer repositions the camera; it only changes `lookAt`.
