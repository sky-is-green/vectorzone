# M5 — The enemy: learning notes (sub-gates 5a–5c)

## Sim architecture learned/built

- **One awareness model** (`awareness.ts`) feeds both the player radar and every
  AI: gunfire reveal (3 s), 30 m proximity, LOS + 5 s memory, scan pings, storm
  blindness, 2 s spawn grace. Contacts carry source + tick so TTLs differ.
- **AI as command producer** (`ai.ts`): brains think on perception ticks and
  emit the same `TankCommand` as players. Between ticks they execute stale
  intent — dodging works because the AI is genuinely behind the world.
- **Director** (`director.ts`): solo escalation by score, one enemy at a time;
  bomber on a 2-minute cadence in every mode; missiles correct early then commit.
- **Telegraphs** are sim entities (`impactTick`), so the ≥1.5 s warning is
  authoritative, not a client animation.

## Bugs caught by tests (the process working again)

1. **AI could never fire**: `thinkBrain` charged the cooldown at decision time
   while `stepWorld`'s fire gate requires cooldown === 0. Cooldown now charged
   where the shot actually fires, per-kind from the knob table.
2. **Stuck detection counted acceleration as stuck**, throwing brains into
   reposition (which suppresses fire). Now position-delta based.
3. Test fixtures: 0.9 m walls cannot block 1.2 m eye-level LOS (towers can);
   think-level tests must seed/refresh awareness themselves; bomber altitude
   lowered to 15 m and gun elevation raised to 60° so it is actually shootable
   (design consequence: anti-air needs elevation, recorded for play-test).
4. Composer + `renderer.info`: stats reset per pass, so the draw-call gate now
   sets `info.autoReset = false` and resets once per frame.
5. Empty rubble geometry → NaN bounding sphere warning; `frustumCulled = false`.

## Pass 4 — match end & ramming (user direction 2026-11-25)

1. **Match end froze nothing and showed nothing**: sim set `phase:'over'` but
   the client kept stepping and had no results UI. Now `stepWorld` returns
   early when over (world freezes), the client stops stepping, and a results
   overlay shows MATCH COMPLETE / GAME OVER, final score, a local top-5
   leaderboard (localStorage), and PRESS R TO RESTART. Deathcam holds on the
   wreck during the 3 s respawn delay.
2. **Ramming**: destructible structures previously didn't interact with tanks
   at all, and indestructible solids didn't block shells. Now: tanks plow
   through structures smashing blocks in their path (speed ×0.85 per contact
   tick, block score credited); obstacles hard-stop tanks AND stop shells
   (slab test at shell step). Tests cover all four behaviors.
3. Probe lesson: classic walls sit at x=-20 and x=35 — aim ram tests at real
   geometry, and remember a 4 m ram swath fully consumes a 3 m wall.

Verification: 63 tests; browser shows plow-through (wall 30→0 blocks, tank
past it, +150 score), frozen world + leaderboard overlay at T-0:00; zero
console errors; 139.5 KB gz.

## Pass 5 — no indestructible class (user correction 2026-11-25)

User: "the things that already occupy the world cannot be destroyed… you
didn't actually change how the current environmental objects work." Correct:
pass 4 only made the *added* structures destructible; the classic cubes and
pyramids were still the indestructible Obstacle class.

Now retired entirely: `SOLID_PLACEMENTS` (13 cubes/pyramids, faithful shapes)
are built as structures from `solidGrid()`; the Obstacle type, hard-stop
collision, and shell-blocking slab path are deleted. Every environment object
rams apart, tunnels, collapses, and leaves rubble.

Verification: 62 tests; browser rammed a classic cube 216→72 blocks and passed
through; one shell tunneled a classic pyramid; 18 structures, 40 draw calls;
zero console errors; 138.0 KB gz.

## Pass 3 — user play-test feedback (2026-11-25)

1. **"No enemies"**: spawns were at 150–190 m, outside the 150 m sight range,
   so brains had no contact and patrolled idle forever. Spawn ring moved to
   100–140 m (inside sight) and first spawn to 2 s — enemies now acquire you
   and come to you, faithful to 1980. Test asserts contact + closing distance.
2. **Radar orientation** (user request): own hull arrow + turret aim tick at
   scope center; every contact blip carries a heading tick.
3. **Bomber/missile kill feedback**: airburst explosion event at the kill
   position (no ground damage) + `BOMBER DOWN` alert; previously they vanished
   silently.
4. **Eruption stall**: client structure sync assumed bodies existed for every
   structure; mid-match rock clusters had none → `refreshBody(undefined)` threw
   every frame → render loop dead. Bodies now created on first sight.
5. **Self-destroying aftermath**: rock clusters spawned at the impact centre
   were erased by their own creating explosion. Rocks now deposit beside the
   crater (clamped to arena); test asserts they survive.
6. Lava pools now render as pulsing hazard rings.

Verification: 59 tests; browser shows enemy closing (109 m), radar contact +
orientation, eruption advancing with rock cover + lava visible, zero console
