# M4 — Phosphor: learning notes

## three.js concepts used

- **EffectComposer / render targets**: the frame becomes a chain of fullscreen
  passes — RenderPass → UnrealBloomPass → CRT ShaderPass. Learned the hard way:
  the composer *overrides* each pass's `renderToScreen` from its own flag every
  render, and swaps read/write buffers after each `needsSwap` pass — so
  readback probes must toggle `composer.renderToScreen` and read `readBuffer`.
- **First GLSL fragment shader** (`post.ts`, commented): barrel distortion
  (radius² push), scanlines (sin over pixel rows), rolling refresh band,
  vignette (smoothstep), mains flicker, and **phosphor persistence** — a
  feedback loop via `FramebufferTexture` + `copyFramebufferToTexture`,
  max-blended with the previous frame for afterglow.
- **LDR byte targets**: the composer was given an `UnsignedByteType` target so
  verification readback into `Uint8Array` works (default half-float reads zero).
- **Palette as material registry**: one apply function recolors shared
  materials, rebuilds the GridHelper (its colors are baked vertex colors),
  and retints future particle spawns; existing particles fade out naturally.

## Verification (numeric — desktop window was hidden, rAF paused)

Hidden windows pause `requestAnimationFrame`, so screenshots and the FPS
overlay were unavailable. All acceptance criteria were instead verified by
render-target readback of the *same centre region*, scene vs post chain:

- **A1 bloom**: B&W lit pixels 143 → 221 with bloom on (glow spreads energy);
  faces still occlude (wireframe off 143 vs on 238 lit).
- **A2 CRT**: post mean (9,233,34) vs scene (10,255,37) with CRT on;
  (10,249,36) ≈ scene with CRT+bloom off → effects present and toggleable.
- **A3 palettes**: post means green (10,238,36), amber (238,108,0),
  cyan (9,184,238), B&W (162,162,162 neutral); HUD stats color follows.
- **A4**: safe mode zeroes `uPersist/uRoll/uSafe→1`; wireframe toggle hides
  face materials (`material.visible`).
- **A5**: full post chain costs **0.47 ms/frame** in the harness (huge margin).
- **A6**: settings survive reload (localStorage; panel label + HUD color).

**Pending human eyes:** the actual *look* of glow/CRT (feel/visual item F3) —
screenshots resume when the desktop window is visible.

## Decisions & deviations

- B&W palette makes hazards white: telegraph rings/shapes carry the danger
  signal there (hue law applies to colored palettes). Recorded.
- Settings panel is minimal DOM now; full settings page is M8.
- `sample()` dev probe added to `__vz` (centre-region readback, scene or post).

## Bugs caught during verification

1. Half-float composer target → zero readback; fixed with byte target.
2. `pass.renderToScreen` overridden by composer; probe fixed to composer flag.
3. Corner readback window was empty ground; probes now read centre region.
