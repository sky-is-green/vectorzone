## Built

- **Gamepad** (`input.ts`): left stick drive, right stick aim, A/RT fire,
  deadzone 0.15; merges over keyboard only when actually touched.
- **Screen shake**: decaying amplitude fed by fire/explosion/kill events,
  applied as camera jitter after the rig; settings toggle.
- **Settings page**: shake, FOV (50–90), resolution scale (0.5–1), map select
  (reloads into the chosen arena), master/sfx volumes (consumed by M6).
- **Arena presets** (`maps.ts`): CLASSIC / OUTPOST / RUINS / STORMFIELD as
  data — placements, fences (pylon ids assigned by placement order), sky
  profiles. `createWorld(seed, map)`.
- **Sky events** (`sky.ts`): ion storms (7 s, blind radar/AI, aurora bands
  client-side) and meteor showers (streaks + rare real meteorites that
  telegraph and deposit rock cover). Per-map profiles; classic stays calm.
- **Perf pass**: heaviest map (ruins, 19 structures) = 38 + ~14 fixed calls,
  inside the <100 gate; test asserts the budget for every map.

## Bugs caught
