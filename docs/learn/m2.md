# M2 — The arena: learning notes

## three.js concepts used

- **Fog** (`THREE.Fog`): linear depth fade to black. The arena floor grid fades
  into the void; **horizon materials set `fog: false`** so mountains, volcano,
  and moon stay crisp at 620 m. Fog is per-material, which is exactly the
  control we need for layered depth.
- **Procedural geometry**: mountain ring = `LineLoop` from layered sines;
  volcano = `LineSegments` cone rings + spokes; crescent moon = outer arc +
  offset inner arc closed into a `LineLoop`. No assets, all math.
- **GridHelper**: one-call ground grid (80 divisions over 400 m = 5 m cells).
- **Geometry merging across entities**: all indestructible solids baked into
  world space and merged (`mergeGeometries` from three/addons) → **2 draw calls
  for the entire obstacle set**, same face/edge builder as tanks.
- **Frustum culling is real**: draw calls varied 9–11 between views because
  off-screen horizon objects get culled. The <100 gate holds with margin.
- **Additive blending + vertex colors** for particles: fading color toward
  black = fading to invisible on the void. One pooled `LineSegments`,
  `DynamicDrawUsage`, `frustumCulled = false`.

## Sim concepts used

- **Maps are data**: `CLASSIC_OBSTACLES` is a hand-authored list; obstacles are
  block grids too (`obstacleGrid`), so one representation still rules everything.
- **Circle-vs-AABB collision** with push-out along the contact normal and a
  shallowest-axis eject for the degenerate inside case; scrape dampens speed.
- **Tolerant layout parsing**: stepped pyramids shrink per layer; missing
  rows/chars parse as empty. (The gate caught the original rectangular
  assumption — see below.)

## Decisions & deviations

- Tank collision uses a circle approx (radius = half hull length, 1.8 m).
  Adequate for sparse solids; revisit if tight-structure navigation feels bad.
- Chase camera added as the second mode (`C` toggles), per BUILD M2.
- **Dev hook `__vz.step(commands, ticks)`**: synchronous sim stepping for
  browser probes. Wall-time probes proved unreliable — background tabs
  throttle rAF and the dt clamp rightly refuses to fast-forward, so a "hold W
  for 4 s" probe under-drives the tank. Deterministic stepping is the honest
  way to probe mechanics in-browser.
- Cosmetic particle randomness uses `Math.random` client-side; invariant I3
  (seeded RNG) applies to the *sim*, not to visual-only wisps. Recorded.

## Bugs caught by the gates (the process working)

1. `parseLayout` assumed rectangular layers; pyramid layers shrink in both
   axes → out-of-bounds row read. Fixed: tolerant parser + centered layouts.
2. Volcano smoke invisible: particle material inherited fog and was fully
   fogged at 620 m. Fixed: `ParticlePool(max, fog)`; horizon emitters pass
   `fog: false`.
